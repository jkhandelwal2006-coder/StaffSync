StaffSync - Modern human resource management solution.


The StaffSync - Modern human resource management solution. is a comprehensive web-based application built using the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)** that streamlines and automates various HR processes within an organization. The system provides distinct roles and access levels for **HR personnel, managers, and employees**, ensuring efficient management and transparency across all operations. HR can manage employee data, handle leave approvals, track attendance, and post announcements or news. Employees can apply for leaves, maintain their personal records, mark attendance, and stay updated with company announcements. Managers can oversee leave requests and manage training and development programs for their teams. This centralized platform enhances productivity, improves communication, and promotes a seamless workflow across departments by digitizing core HR functions.

ER-DIAGRAM:

Explanation of the HRM System ER Diagram
The Entity-Relationship Diagram (ERD) represents the core data structure of the Human Resource Management System (HRM). It defines how various entities such as Employee, Manager, LeaveRequest, Attendance, and Announcement are related.

Employee Entity

Attributes: EmployeeID, FirstName, LastName

Each employee can submit multiple leave requests and has associated attendance records.


Manager Entity

Attributes: ManagerID, FirstName, LastName

A manager can approve leave requests submitted by employees and can also post announcements for the organization.


LeaveRequest Entity

Attributes: StartDate, EndDate, Status

Represents a leave application submitted by an employee and approved or rejected by a manager.


Attendance Entity

Attribute: Date

Keeps track of the daily attendance records of each employee.


Announcement Entity

Represents organization-wide news or updates posted by managers or HR personnel.

Relationships
Employee → LeaveRequest: An employee submits a leave request.

Manager → LeaveRequest: A manager approves or rejects a leave request.

Manager → Announcement: A manager posts announcements for employees.

Employee → Attendance: An employee records attendance daily.

MVC PATTERN:

The HRM Tool backend application follows the Model-View-Controller (MVC) architectural pattern, a software design approach that separates an application into three interconnected layers. This separation allows for modularity, easier maintenance, and scalability.

Model Layer (Data Layer)

The Model layer is responsible for handling all data-related logic. This includes the definition of data schemas and the operations performed on the database using those schemas. The models are implemented using Mongoose, which provides a schema-based solution to model application data for MongoDB.


Controller Layer

The Controller layer acts as an intermediary between the view (routes) and the model. It receives incoming requests, processes the input (which may include validation or transformation), calls the appropriate methods from the model, and then returns a response to the client.

View Layer (Routing Layer)

In the context of a backend REST API, the View is implemented as the routing layer, where various endpoints are defined. These endpoints determine how the backend responds to different HTTP requests (GET, POST, PUT, DELETE) and are responsible for invoking the appropriate controller functions.

Advantages of Using MVC in This Project

Separation of Concerns: Each layer has a clearly defined responsibility, improving readability and maintainability.

Scalability: New features can be added easily by creating new routes, controllers, and models.

Reusability: Logic in controllers and models can be reused across multiple parts of the application.

Testing: Each layer can be tested independently, especially the controllers and models.

Collaboration-Friendly: Multiple developers can work simultaneously on different layers without conflict.

STEPS FOR PROJECT EXECUTION:
Description
 Step 1: Download and Open the Project

First, clone or download the project folder (HRM Tool) from the repository or your local source.

Once downloaded, open the project folder in VS Code or any code editor of your choice.

You will see two main subfolders:

client → contains the frontend (React) code
server → contains the backend (Node.js + Express) code


Step 2: Set Up the Frontend (React App):

  a) Open a terminal and navigate into the client folder:

        cd client

  b)  Install all the required frontend packages:

        npm install

c) Once installation is done, start the React development server:

      npm run dev

d) The app should now be running on:

     http://localhost:5173

Step 3: Set Up the Backend (Express Server)

  a)  Open a new terminal tab/window or split the terminal.

  b) Navigate into the server folder:

        cd ../server

  c) Install all backend dependencies (like Express, Mongoose, etc.):

      npm install




Step 4: Configure Environment Variables

Inside the server folder, create a new file named .env (no file extension).

In that .env file, add your MongoDB connection string:

           MONGO_URI=mongodb://localhost:27017/hrm

     

Step 5: Start the Backend Server:

Inside the same server folder, run the backend server using:

             nodemon index.js

The server should start on:

http://localhost:8000
